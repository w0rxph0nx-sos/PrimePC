| 2) ชื่อโครงงาน (Project Title)

ชื่อโครงงาน (ภาษาไทย): ร้านค้าออนไลน์สำหรับจัดจำหน่ายอุปกรณ์คอมพิวเตอร์ (PrimePC)

ชื่อโครงงาน (ภาษาอังกฤษ): PrimePC

| 3) หลักการและเหตุผล (Rationale)

ในปัจจุบันการเลือกซื้ออุปกรณ์คอมพิวเตอร์ผ่านช่องทางออนไลน์ได้รับความนิยมมากขึ้น เนื่องจากผู้ใช้สามารถเปรียบเทียบราคา ดูรายละเอียดสินค้า และสั่งซื้อสินค้าได้สะดวก โครงงาน PrimePC จึงถูกพัฒนาขึ้นในรูปแบบแพลตฟอร์ม E-Commerce เพื่อจำหน่ายอุปกรณ์คอมพิวเตอร์ เช่น CPU, GPU, RAM, Mainboard และ SSD โดยเน้นการใช้งานที่ง่าย มีข้อมูลสินค้าชัดเจน และรองรับการพัฒนาต่อยอดในอนาคต

| 4) วัตถุประสงค์ของโครงงาน

  • เพื่อพัฒนาแพลตฟอร์ม E-Commerce สำหรับจำหน่ายอุปกรณ์คอมพิวเตอร์
  • เพื่อให้ผู้ใช้สามารถดูรายละเอียดสินค้าและเลือกซื้อสินค้าออนไลน์ได้
  • เพื่อออกแบบระบบตามแนวคิด SDLC และสถาปัตยกรรมซอฟต์แวร์เบื้องต้น

| 5) ขอบเขตของระบบ (System Scope)

ลูกค้า (Customer)

  • สมัครสมาชิกและเข้าสู่ระบบ (Login)
  • ดูรายการสินค้า เช่น CPU, GPU, RAM, Mainboard และ SSD
  • ค้นหาและดูรายละเอียดสินค้า
  • เพิ่มสินค้าในตะกร้า และสั่งซื้อสินค้า

ผู้ดูแลระบบ (Admin)

  • จัดการข้อมูลสินค้า เพิ่ม แก้ไข และลบสินค้า
  • ตรวจสอบคำสั่งซื้อของลูกค้า
  • จัดการข้อมูลสมาชิกและข้อมูลพื้นฐานของระบบ

| 6) แนวทางการพัฒนาตาม SDLC

ขั้นตอน รายละเอียด
Planning กำหนดหัวข้อโครงงาน วัตถุประสงค์ และขอบเขตของระบบ
Analysis วิเคราะห์ความต้องการของผู้ใช้และฟังก์ชันที่จำเป็น
Design ออกแบบหน้าเว็บไซต์ โครงสร้างข้อมูล และการทำงานของระบบ
Development พัฒนาเว็บไซต์ด้วย HTML, CSS และ JavaScript
Testing ทดสอบการแสดงผล ปุ่ม เมนู และความถูกต้องของข้อมูล
Deployment เผยแพร่เว็บไซต์ผ่าน GitHub Pages

| 7) เครื่องมือและเทคโนโลยีที่ใช้

  • Frontend: HTML, CSS, JavaScript
  • Version Control: GitHub และ SourceTree
  • Editor: Visual Studio Code
  • Deployment: GitHub Pages

| 8) ประเภทการทดสอบ (Test Types)

  • User Acceptance Testing (UAT)
  • Manual Testing
  • ตรวจสอบการเชื่อมโยงเมนูและหน้าเว็บไซต์

| 9) ผลลัพธ์ที่คาดว่าจะได้รับ

  • ได้เว็บไซต์เอกสารโครงงาน PrimePC ที่สามารถเผยแพร่ผ่าน GitHub Pages ได้
  • ผู้ใช้สามารถเข้าใจขอบเขตและแนวคิดของระบบร้านค้าออนไลน์ได้
  • สมาชิกในกลุ่มเข้าใจกระบวนการพัฒนาระบบตาม SDLC

| 10) แผนการดำเนินงาน 4 สัปดาห์

สัปดาห์ รายละเอียด
สัปดาห์ที่ 1 วิเคราะห์หัวข้อ กำหนดขอบเขต และวางแผนโครงงาน
สัปดาห์ที่ 2 ออกแบบหน้าเว็บไซต์และโครงสร้างข้อมูล
สัปดาห์ที่ 3 พัฒนาเว็บไซต์และจัดทำเนื้อหาโครงงาน
สัปดาห์ที่ 4 ทดสอบ แก้ไขข้อผิดพลาด และเผยแพร่ผ่าน GitHub Pages
